# Issue bodies are shown, sanitised, in a detail view

The detail view shows an issue's body, rendered from its markdown, where until now nothing from GitHub but sanitised titles reached the terminal. Reading a ticket without leaving the terminal is the point of the view, and the body is most of a ticket. It is made safe by sanitising every string: the body is stripped of escape sequences line by line before parsing, and every text, code and link segment is sanitised again once parsed, since entities like `&#27;` can make new ones. The only escapes in the output are the renderer's own styles and OSC 8 links, and links become hyperlinks only for `http`, `https` and `mailto` URLs. The markdown is parsed with goldmark (one module, no dependencies of its own) and walked by our own renderer (`internal/markdown`). Glamour was rejected: it strips raw HTML, so `<img>` tags vanish, it has no hook for images, and it adds about 12 modules.

## Consequences

Any new string from GitHub must go through `wayfinder.Sanitize` or the markdown renderer before it is shown; `Issue.Body` is the one unsanitised field and must only reach the screen through the renderer. Raw HTML in a body is reduced to its text, and images show as a `🖼 alt` placeholder until inline images land. Evidence: [Detail view: explore a ticket with its body, mini-map, images and relationships](https://github.com/distrail-io/wayfinder-map/issues/25).
